## D005 — M0 SVG 工具的解释边界（2026-10-16）

按 14.4 支持规定元素、路径简写/弧线/二次曲线及矩阵/平移/缩放/旋转/倾斜变换。SVG 入口视为数值几何交换：有 viewBox 时直接使用其坐标单位并翻转 y，不根据根 width/height 二次缩放；无单位/px 的元素数值按 1pt，显式物理单位换算为 pt。此为开发预览约定，不代表浏览器 CSS 像素物理尺寸。

优先采用 viewBox 或根 viewport 建立 artboard；缺失时用控制点范围兜底并输出警告，不假称已实现 M1 精确包围盒。嵌套 viewport、DTD、非法数值/变换显式报错；文本、use、外部 CSS、剪切和蒙版不展开，跳过或警告。复合轮廓遵循现有 even-odd 契约；源 nonzero 可能不一致时警告。变换不轮廓化描边，明确警告。M0 预览仅浅灰原始几何，lg-guides 为空；完整深浅色辅助样式留到后续。

## D008 — S 与归一化顺序、退化尺度和采样下限（2026-10-16）

原规范 normalize 需要 S 判断 cubic 是否可直线化，但流水线在 rows 步骤才正式建立 S。M1 先用原始 cubic 解析极值的精确包围盒执行 rows 建立尺度，再做 S 相对直线判定，保留原曲线精确包围盒；采样使用该尺度。这不增加公共数据契约，未来流水线可复用结果。

完全水平的开放线条没有正行高，原文又要求开放路径参与检测，因此仅在所有行高为零时使用 D 作为计算尺度并记录 ZERO_ROW_HEIGHT 警告。零弦长段仍按原文丢弃。

采样先按比例增大 h，最多 32 次；如接近每段 4 点的下限导致 ceil 平台，则统一增大到四点可覆盖的间距。若 cubic 数×4 本身超过 maxSamples，两个硬要求无法同时满足，显式报错提示调高预算，不静默丢轮廓或超预算。

## D010 — M2 阶段流水线与尚未计算的 a（2026-10-16）

M1 真实导出已通过第 15 节门槛，继续到 M2 的基准线绘制用户验收点。M2 以原有 `analyze → { analysis, render }` 契约输出真实参考线；未实现的测量特征数组为空，不产生模拟测量或圆。自动 a 在 M3 才实现，所以 `analysis.baseUnit.value/source` 暂为 null、candidates 为空；Doc Data 的对应值为 null 且 locked=false，不能伪造 auto-stem 来源。明确给定的手动 a 原值写入，来源 manual，按设置锁定。M3 再补全自动 a。

Generate 暂用第 7 节默认设置，不提前实现 M6 对话框、全局设置、Refresh/Clear。标签构造、估算和宿主多行绘制已经实现并自动测试，但参考线阶段不会生成尺寸标签。M2 竖参考线使用支撑行上下外扩 fs 的基础跨度，M3 加入实际车道后补全。曲线重复极值按同一轮廓、同一类型去重，保留不同轮廓证据以支持 mixed 分类。多数极值类型平票时按 top 处理，结果确定。

## D011 — F9 的平直基准线与通用保留阈值冲突（2026-10-16）

第 8.6 节的通用保留条件与第 14.2 节 F9 的明确验收期望冲突：F9 的 I 上下边各 20pt，小于 `lineKeepFlatRel × S = 0.3 × 104 = 31.2pt`；每簇只有一个部件，且 O 的超出簇是最外侧，因此通用条件会丢弃 y=0/100，而 F9 明确要求它们为 baseline/flat。

采用最小冲突处理：只有已满足保留条件且满足超出距离/方向判定的曲线簇，才额外保留它所依附的最近平直簇。既满足 F9，又保留平直与超出线的语义配对；不降低全局阈值、不改第 7 节、不对所有短平边放宽。自动测试固定验证 F9 的 4 条水平线，并覆盖平移/缩放不变性。

## D013 — M3 配对、并列值与缓存（2026-10-16）

为落实“每条边只与 d 最小的对边配对”，采用双方互为最近的候选，等距时保持边遍历顺序，避免一条边被重复使用。交断共线笔画合并后宽度按重叠长度加权，mid 保留最长片段中点。加权中位数恰好半权重时取较小值；最高得分并列取较小宽度。右侧车道跨行统一防碰撞，labelDedup 仍限定同行。

preAnalyze 通过 analyze 第三个参数复用上下文；只比较完整第7.2/7.3解析数值（含EPS），另核对输入几何相同，避免误用旧选区。显示设置改变不阻止几何缓存，lines/stems 总重算。上下文克隆后使用，避免后续布局污染缓存。

## D014 — M4 数值与手动拟合（2026-10-16）

Kåsa 在居中后再按点集尺度归一化，保持附录A的同一公式并减少大坐标数值误差；LM初始λ=0.001，改善时除10、拒绝时乘10，最多20次，步长小于阈值立即结束。闭合接缝的递归中点用相邻采样距离累计，避免原轮廓arcLength回绕。只有段连接处判断角点，防止把同一曲线内正常转角错误拆开。

手动拟合使用PathPointSelection.ANCHORPOINT，选中手柄不视为选中锚点；误差报告只统计选中锚点，拟合仍含双端选中段的采样。M4入口暂用默认设置，M6接入全局设置。三角边长按0.6fs等边构造。圆的full越界回退在全部标签计算后的最终辅助区域判定。

F10性能优化仅减少数学函数的临时数组、重复拟合和无效LM迭代，不改参数/采样。测试文件串行运行，测量只包含对预建Geometry调用analyze，避免测试进程竞争混入性能指标。

## D015 — M5 扇区、目标线与预览背景（2026-10-16）

夹角对同一簇对和显示角去重，长度和相同时保留遍历首项；上下空白扇区不额外重复显示。轴角保留参考轴与旋转方向供目标射线使用，有符号模式的右倾/上升为正。所有目标线沿原中线/顶点构造，不移动原图形；合并笔画用全部片段的投影范围。

图例按第9.8节从下往上放置，final区域由A0与图例框并集决定，之后裁剪构造线和处理圆回退。SVG背景位于lg-guides内，背景之后通过use重绘已有lg-geometry，再画其他辅助图元；导入器跳过整个辅助组，所以不会重复导入图形。背景为可选且默认关闭，没有增加依赖。

## D016 — M6 状态、异常与计时（2026-10-16）

全局设置损坏时报告实际路径并停止，不静默覆盖。生成窗口取消不写设置、不替换图层；确认后按第10.6节保存。刷新保留文档锁定a及首次source；未锁定时更新值/source，但保持文档locked=false，避免其他文档改变全局locked选项后把本文件意外锁定。SetBaseUnit只写文档a，不改全局偏好。

Clear的“全部辅助线”保留隐藏文档数据与来源标签，只有“全部+文档数据”删除根层和LG_SOURCE。删除前先确定仍能恢复的选区和活动层，避免对已删除的Illustrator对象再读属性。若原活动层恰是被替换的自动子层，改恢复现存的第一个原图层。标签修改暂时解锁对象及祖先，再按相反顺序恢复；异常恢复仍存在的图层锁定，不宣称事务式恢复已删除图元。

手动工具保存并恢复每个锚点的选择枚举，避免给doc.selection重新赋值时把局部选点变成全选。独立锚点没有共享曲线时直接拟合，省去不必要的Geometry归一化。稀疏采样下，圆run角点改比较精确端点的前进切线，处理重合手柄的方向极限。

生成/刷新日志ms包括读取、预分析、分析、绘制与设置读写，排除用户在窗口停留的时间；F10核心指标仍只测预建Geometry的analyze。摘要按|dev|列最多5项，各项保留自身%或°单位。SVG视口按实际图元外界扩展以防裁掉整圆/安全区，核心guideArea、构造线裁剪、圆显示回退仍按第9.7节，不新增参数。

M6最终文件布局与第5节六个host编号一致：手动圆边界归入h04_draw，交互流程与窗口归入h06_dialog；LG.hostManual/hostActions命名空间保持不变，不新增宿主文件编号或数据格式。

## D018 — 原生探针及失效图层引用（2026-10-16）

桌面窗口截图持续超时，但Illustrator COM与可访问性控件读取可用，因此使用同份core/host的原生ExtendScript探针，测试独立创建的RGB/CMYK文件。探针的设置选择仅在内存中注入，不写全局settings.json；另用真实ScriptUI窗口和按键测试交互及撤销。原生导出PNG证明实际绘制与中文标注，不能代替画布拖动或窗口像素证据。测试工具不进入发布脚本。

实测发现：删除Layer之后，对失效原生对象做严格相等比较也可能抛“对象无效”，而Node普通对象没有这种行为。恢复锁定/活动层时只对引用比较捕获失效异常、跳过已删层，仍恢复活层；实际设置locked失败仍向上传播。RGB/CMYK三种Clear复测均通过。

F10真实2000锚点生成99,609ms，目标15秒未达到。依第14.5节第9项记录并列入M7计算迁移/刷新性能优化，不通过减少采样、关闭默认功能或放宽参数掩盖。M7前仍须完成M6剩余拖动验收。

## D019 — M7 面板计算边界与性能证据（2026-10-16）

面板计算必须使用 V8 中的同一份 core；ExtendScript host 只读取 Geometry、校验并执行一次绘制。F10 在 Illustrator ExtendScript 中全量计算约 117 秒，不能作为 CEP 面板性能结论，因此只保留为回退基线；Node V8 对同一预建 2000 锚点 Geometry 的 `preAnalyze → analyze` 为 307ms。F9 原生 host read、等价 V8 计算和单次 draw 总计 758ms，作为桥接证据。真实 CEP UI 和 2000 锚点完整 CEP 链仍需在 Illustrator 面板中实测，未提前标记 M7 已验收。

刷新隐藏状态按类型及 Geometry key 最近一对一匹配，绝不只用可变化的 feature id；坏的旧 key 直接跳过。精选模式只限制线/构造线、圆和角度，笔画与间距完整保留。面板在 host draw 前校验 read token、文档、模式、runId、有限几何和样式，验证失败时不删除旧图层。
