## 在 Illustrator 中操作

1. 打开一个 RGB 文档，画一个矩形和一个圆，编组后选中。也可直接选择自己的矢量 Logo。
2. 从“文件 › 脚本 › 其他脚本”运行项目 `dist/scripts/LogoGuides_DumpGeometry.jsx`。
3. 应弹出导出成功提示，显示实际 `geometry_dump.json` 路径和部件/警告数量。文件位于 Illustrator `Folder.userData/LogoGuides/`，Windows 通常为 `%APPDATA%\LogoGuides\geometry_dump.json`，以弹窗为准。
4. 确认原图形、编组和文字仍存在，没有临时转曲副本残留，选区和活动图层恢复。这个脚本只导出，不生成辅助线。
5. 再选择包含复合路径（例如圆环）及未转曲文字的图形运行。复合路径应作为一个部件，文字应以临时轮廓读取；原文字仍可编辑。每次导出会覆盖前一次 JSON，请及时复制需要保留的样本。
6. 在 CMYK 文档重复一次；可用直接选择工具选复合路径子路径，检查仍读取完整复合路径。选区内的位图会被跳过并写警告，不会自动描摹。
7. 可选异常检查：无打开文档/无选区/文字编辑状态时应提示；未生成 JSON 时查看同目录 log.txt。

## Node 读取与预览

在项目根目录运行（替换为弹窗中的实际路径）：

```powershell
npm run validate:geometry -- "C:\实际用户目录\LogoGuides\geometry_dump.json" dist/validation/illustrator-m1.json
npm run preview -- "C:\实际用户目录\LogoGuides\geometry_dump.json" --out dist/previews/illustrator-m1.svg
```

当前机器 npm 不在 PATH 时使用：

```powershell
$npmRunner = 'C:\Users\disen\.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd'
& $npmRunner dlx npm@10.9.4 run validate:geometry -- "导出文件实际路径" dist/validation/illustrator-m1.json
& $npmRunner dlx npm@10.9.4 run preview -- "导出文件实际路径" --out dist/previews/illustrator-m1.svg
```

验证命令应退出为 0，报告中 parts/anchors/rows/S/D 有效，数值有限，采样数不超过上限。SVG 应保留原几何与孔洞，y 方向正确；这里还没有辅助线或标注。
