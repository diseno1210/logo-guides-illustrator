## 当前阶段能力

- 读取原选区，按真实几何生成水平/竖直参考线；平直、圆形边界、mixed、overshoot 按第 8.6 节分类。
- 基准线为灰色虚线，视觉线为红色实线（默认 dark）；辅助区域按包围盒外扩 0.2D。
- 独立 Logo Guides 顶层与按需创建的 LG Baselines / LG Visual Lines 子层；默认锁定，恢复原活动图层和来源选区。
- `__LG_DATA__` 隐藏路径保存 schemaVersion/runId/baseUnit/hiddenFeatures/时间；原来源对象写 LG_SOURCE 标签。除标签外不修改来源几何。
- 当前无尺寸/倍率标签、拟合圆、角度、图例、对话框或刷新/清除脚本。不要按完整产品预期验收。重新运行 Generate 是重新生成；M6 才提供 Refresh。

## 操作步骤

1. 在文档副本中测试，保留原稿。选中矢量 Logo（可以沿用这次 BOATCHIN）。
2. Illustrator「文件 › 脚本 › 其他脚本」选择工作区 `dist/scripts/LogoGuides_Generate.jsx`。请使用本次重新构建的 M2 文件。
3. 成功提示应显示 `Logo Guides M2`、参考线条数和警告数。若使用与已导出样本完全相同的 BOATCHIN 几何，Node 参考结果是 **12 条、0 警告**；以实际选区为准。
4. 检查画面：有灰色虚线与相应的红色视觉线，线与轮廓位置合理；Logo 本身保留；没有临时轮廓残留。
5. 展开图层：Logo Guides 位于最上方并锁定；本样本应有 LG Baselines 和 LG Visual Lines；有隐藏 `__LG_DATA__`。活动图层应仍是原来的绘图层，来源对象仍选中。
6. 再运行一次 Generate，辅助线应替换而不叠加重复的自动子层；如果存在 LG Manual，应保留它。此项是 M2 绘制实现的回归检查，不代表 Refresh 已实现。

只验证简单基准线也可：画 3 个矩形，宽均为 20pt、高均为 100pt，x 分别为 0/40/80pt，底部对齐，编组并选中。预期 2 条水平线 + 6 条竖线，共 8 条灰色虚线。
