# M6 Illustrator 用户验收

依据：[DEV_PLAN第14.5节](../DEV_PLAN.md#145-illustrator-手动验收清单用户执行)。原文规定“14.5清单由用户确认”；本页是操作记录，不增加验收门槛。

当前状态：**自动验证通过，以下12项均待本次真实Illustrator验收**。Node DOM/ScriptUI双替身只能证明调用逻辑，不能证明原生窗口、颜色、参考线吸附或撤销行为。M2历史截图证明当时12条参考线和图层绘制通过，不直接代替M6完整验收。

## 准备

- 使用当前`dist/scripts/`中的六份JSX。先运行Generate；其他脚本通过“文件 › 脚本 › 其他脚本”选择即可，无须安装面板。
- 环境记录：Illustrator版本：待填写；系统版本：待填写；日期：待填写。
- 建议准备RGB和CMYK各一份测试文档，以及包含编组、复合路径、未转曲文字的Logo。保存原文档，以便对照原图形和文字。
- 日志位置：Illustrator的Folder.userData/LogoGuides/log.txt（Windows通常是%APPDATA%/LogoGuides/log.txt）。

## 原文12项清单

| # | 操作与预期 | 实测结果 |
| --- | --- | --- |
| 1 | RGB和CMYK各运行Generate；检查灰色虚线、视觉线及标签颜色。白底可选light。 | 待验证 |
| 2 | 选择包含编组、复合路径、未转曲文字的Logo运行Generate；原文字保留且无残留临时轮廓副本。 | 待验证 |
| 3 | 检查Logo Guides按需包含第10.1节子层及隐藏__LG_DATA__；默认锁定，活动图层仍是原图层；可选背景在最底。 | 待验证 |
| 4 | 保持锁定a，用直接选择移动一个锚点，再运行Refresh；辅助结果更新，摘要/文档a保持原值。 | 待验证 |
| 5 | 只选部分路径运行Refresh；仍针对全部来源对象，来源选区恢复。 | 待验证 |
| 6 | 分别试Clear三种模式：仅自动保留Manual/数据/标签；全部辅助保留数据/标签；全部+数据删除根层/背景/LG_SOURCE；原图形不变。 | 待验证 |
| 7 | 直接选择至少3个锚点运行CircleFromSelection；圆与半径/最大偏差标签进入LG Manual；Refresh后仍在。 | 待验证 |
| 8 | 中文窗口、中文偏差、图例没有乱码。需要英文时编辑uiLanguage=en后重开Generate。 | 待验证 |
| 9 | 约2000锚点Logo运行Generate，记录日志ms（含读取/分析/绘制，排除窗口停留）；目标≤15秒，超出则列入阶段2优化。 | 耗时待记录 |
| 10 | Generate选择guides模式；确认线/圆/弧为原生参考线，标签/图例仍可见；拖动锚点并记录能否吸附。 | 参考线/吸附待记录 |
| 11 | Generate后只按一次Ctrl/Cmd+Z，记录撤销范围是整次还是单个对象，写入DECISIONS。 | 撤销范围待记录 |
| 12 | Alt/Option拖动复制来源对象后Refresh，记录副本是否被识别、LG_SOURCE是否随复制，写入DECISIONS。 | 复制标签行为待记录 |

前两种Clear之后可Refresh重建；第三种之后必须重新Generate。测试SetBaseUnit可在同一文档选一个矩形选择宽度，或选两个锚点选择距离；应锁定新a并自动刷新已有来源。这是已实现P1工具的回归操作，不作为额外里程碑审批。
