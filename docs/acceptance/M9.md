# M9 验收记录

## 自动与本机证据

状态：进行中；M8已验收，M9签名预验收工具已实现，干净机器安装未验证，因此不发布v1.0。

计划完成后执行：

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npm test
npm run build
npm run check:es3
$env:LG_ZXP_SIGNER = (Resolve-Path '.cache/m9/ZXPSignCmd.exe').Path
$env:LG_CERT_PATH = Join-Path $PWD '.cache/signing/logo-guides.p12'
node tools/release.js pack --no-timestamp
node tools/release.js verify --out 'dist/releases/.../*.zxp'
```

预验收应记录：ZXPSignCmd版本与SHA256、证书SHA256、源提交、ZXP SHA256、`release.json`清单、签名验证输出以及是否有时间戳。证书密码、API key和用户目录配置不进入证据。

## 干净机器门槛

由用户在未开启PlayerDebugMode、未装本项目开发扩展的Windows机器完成：

1. 记录Windows、Illustrator、CEP、安装器版本和ZXP SHA256。
2. 使用Adobe官方ExManCmd或其官方指南列出的安装器安装，确认没有调试模式。
3. 重启Illustrator，从“窗口 → 扩展 → Logo Guides”打开。
4. 用两个矩形生成并刷新，确认面板、辅助线和设置工作；关闭再打开面板后重复一次。
5. 卸载并确认扩展不再出现；使用备份包回退安装并确认仍可打开。

截图、安装器日志和错误码可脱敏保存到本地证据目录；原始AI文件和API key不上传。若任一步失败，记录为待验收并保持版本0.3.0。
