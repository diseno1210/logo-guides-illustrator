# v0.3.1 标注可读性验收

2026-10-17。来自用户3张实际使用截图的修正；实施范围见[READABILITY计划](../implementation/READABILITY.md)。M9干净机器验收仍待完成，此修正不等于v1.0发布。

## 原因与行为

- BOATCHIN既有导出及当前CEP状态均可复现。圆C44/C45分别是不同位置的拟合圆，半径约11.048/11.046pt，圆心x相差约3.408pt；最大带符号误差0.215701/0.220262pt，两位小数都显示+0.22pt，不是同一条数据重复写入。原偏差标签固定在各自最大误差点附近，位置相近时叠加。
- 原尺寸车道只处理尺寸类；圆/环偏差和角度标签后加入，没有共同碰撞检查。新布局跨类别避让，在原位置附近寻找空位，必要时移到外侧并以同featureId引线连接；偏差标签增加圆编号，保留不同测量数据。
- 不修改数值算法或来源Geometry；参考线和构造线的显示跨度可随标签外界改变。普通字号自动公式与原样式预设默认值保持原文，新appearance覆盖仅由用户选择启用。
- 新的“整理展示”由用户触发：用自动字号的65%（最低3pt）、浅色样式、延伸圆弧、同值去重和精选，关闭角度/构造线/偏差诊断。此动作调整输出可读性，不删除源数据。可逐项重新开启。

## 限制

标签避让采用字体估算和有限搜索，不承诺任意字体/Logo完全无交叉；圆线避让为位置优化，构造线/参考线仍可能穿过标签或图形。复杂诊断建议先用整理展示，再按需开启类别。未用白色遮罩覆盖原稿。

四条原尺寸车道满时仍保留LABEL_LANES_FULL警告，即使后续跨类避让已经把标签移开；不把该警告本身等同于最终必有重叠。原生参考线的颜色/虚线受Illustrator控制，面板覆盖适用于样式化图形与文字。原生参考线模式需要样式可控时应切换到styled或both。

M9干净机器安装、卸载与回退结果仍需按[M9表](M9.md)补齐。用户“能用”的反馈不自行推断为全部门槛完成。
