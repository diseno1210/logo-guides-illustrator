# v0.3.2 圆弧、线宽与 AI 标注一致性

依据：用户2026-10-17的5张截图及追加要求。沿用DEV_PLAN第6节契约、第7节既有circleExtendDeg、第14/16节验收与ES3约束，不改原规范。

1. 在面板暴露既有circleExtendDeg：0–180°滑块，含每端延伸角度读数；保留默认30°。完整圆/仅拟合圆弧时禁用。AI目标圆和环的目标圆沿用对应拟合弧覆盖与显示模式。
2. appearance增加strokeWidth（物理pt，0自动），统一样式化辅助线宽；AI目标图元继承基准辅助线样式，再应用用户颜色/虚线/线宽覆盖。偏差三角也继承用户线颜色。原生参考线由Illustrator管理。
3. AI区域增加“仅用实测标注”及“恢复目标对照”。新增Settings.measurementLabelMode=compare/measured，默认compare。measured时所有尺寸/角度统一用◇加实际测量的舍入值，不画目标线/目标圆、不显示目标与偏差第二行及圆拟合误差诊断；保留建议、隐藏特征、分析目标和来源几何，恢复无需重新请求。compare仍显示目标和偏差，但第二行用◇代替“实测”。按用户进一步要求，使用空心菱形标识实际测量值，不使用约等于号；数值仍按原实测副行精度显示（倍率三位、角度一位）。
4. 特征管理补用途说明：显隐辅助对象、点击定位，不修改来源；显示类别、编号、数值和格式化偏差，明确无目标时没有偏差。精选按评分减少参考线/圆/角度，笔画等测量仍保留。
5. 自动验证覆盖弧跨度/饱和完整圆、物理线宽host/SVG、目标样式、两种标注模式所有测量类别、会话切换及来源变化拒绝。真实CEP在独立文档验证UI、AI模拟目标应用、实际原生属性、两模式切换、来源/a/隐藏状态不变；不再花费真实AI调用。
6. 完成后更新日志与使用指南，提交推送GitHub，同步固定Notion日志，重打预验包。M9干净机器门槛保持待验。

追加要求：用户要求取值小数位可选且通常为两位。增加labelDecimals=2（0–4整数），仅格式化自动尺寸/半径/角度主行、实测行、偏差值、手动圆及面板测量条目，不改测量/拟合/AI目标数值；基准单位a保留简写。既有labelPrecision与angleLabelPrecision仍控制规范中的量化步长，小数位控制最终显示。
