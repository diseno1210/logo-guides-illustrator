# M7 实施与验收计划

前置：M6已由真实Illustrator和用户拖动验收通过，提交`4d6856b`。依据DEV_PLAN第5、6、7、10、11.4、11.5、14、15、16节；不实现M8 AI或P2自动轮询。

1. 建立CEP11 manifest、官方CSInterface v11和许可证/来源记录；打包到dist/panel。core仍由同份ES3源构建，host保留完整core以支持必要时回退。
2. 宿主暴露原文7个LGHost函数。传参URI编码JSON，统一ok/data或ok/error响应；读取缓存来源引用与文档上下文，绘制前拒绝过期或切换文档的请求。一次生成/刷新只调用一次read和一次draw。
3. 面板本地运行preAnalyze/analyze，继承文档锁定a；复用现有Geometry、Settings、Doc Data、analysis/render。宿主只读/画/存储；默认不在ExtendScript重复计算。
4. 实现与脚本窗口对等的实时参数、a候选/数值/宽高、生成/刷新/三种清除/dump、样式及容差滑杆。区分编辑设置与确认应用；无效输入不替换现有图形。
5. 特征管理：分类/数值/偏差、severity检查视图、选中辅助图元、显示隐藏；隐藏记录写入既有hiddenFeatures，刷新按11.4的类型/部件/几何容差做最近一对一匹配，不能仅靠会变化的id。
6. 精选模式只限制线/圆/角度，规则评分及并列顺序写入DECISIONS；笔画和间距完整保留。改变输出只筛选真实图元，不伪造分析结果。
7. 测试编码/异常/过期调用、隐藏匹配、精选上限、面板与脚本对F1–F10及真实样本图元类型/数量一致、数值差≤1e-6；构建产物执行ES3检查。
8. 在真实Illustrator中测量2000锚点read→面板计算→draw的总刷新时间，目标≤3秒；记录各段与总耗时，不用Node时间代替宿主。必要优化只减少重复工作，不改默认采样/参数。
9. 完成面板渲染检查、原生桥接和真实CEP试用；更新README/USER_GUIDE/CHANGELOG/STATUS/验收证据并提交推送GitHub、同步Notion工作日志。满足M7前不进入M8；任何未通过门槛保持待验证。

当前没有新增运行时/开发依赖。Git 使用本地 `main` 和私有 GitHub 远程 `diseno1210/logo-guides-illustrator`；不创建发布 tag，每个阶段提交后推送。
