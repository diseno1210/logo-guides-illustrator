# 用户反馈：标注可读性与面板样式

2026-10-17，M9干净机器安装仍待验收。用户实际使用反馈授权此修正：标注过大、偏差数值叠加、角度/圆线拥挤，要求面板调整字号、文字/辅助线颜色和虚线。此文件记录主规范以外的明确追加要求；DEV_PLAN正文与算法参数默认值不改。

1. 复现已有BOATCHIN Geometry及当前面板几何，保留before/after本机证据；不改用户原稿。
2. 面板开放已有fontSize、circleDisplay、circleLabels、labelDedup；新增appearance设置存入既有settings.json，分别覆盖全部文字/线颜色和虚线模式、段长/间隔（实际pt）。空颜色/预设模式沿用原预设，提供恢复按钮。纯原生参考线颜色仍由Illustrator控制，界面说明。
3. 新增avoidLabelOverlap（默认true，可关闭）：尺寸车道布局之后，在最终布局阶段检查所有普通标签。拥挤角度/偏差等标签移动到有空位的位置并加入同featureId引线；不删除不同测量值、不改变analysis、来源Geometry或a。线经过文字时可采用断线避让，必须保持特征身份和原始分析信息。
4. “整理展示”明确作为用户触发的面板操作：切换浅色、缩小字号、圆改为延伸圆弧、隐藏角度/构造线/偏差诊断、开启同值去重及精选；不改变正常默认分析设置。复杂Logo不承诺所有文字/线绝对不交叉，警告必须保留。
5. 自动测试验证配置边界与持久化、样式在host/SVG一致、邻近偏差与角度标签分离、不同值保留、原几何与a不变、原有回归与F10性能。真实CEP独立文档检查UI与原生绘制；用户原稿仅做只读复现，不自动重绘。
6. 验证后更新文档、提交推送GitHub和Notion日志；交付新签名预验包。M9安装门槛仍未完成，不宣称v1.0。
